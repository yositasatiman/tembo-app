# กฎระบบ Coin ของ TEMBO

> ฉบับเต็มอยู่ใน Claude Doc: https://claude.ai/artifact/G1VWCbTfdCHmRB6AKAkRgA
> ไฟล์นี้สรุปไว้ให้คนเขียนโค้ดอ้างอิง ถ้าสองที่ไม่ตรงกัน ให้ถือ Claude Doc เป็นหลัก แล้วแก้ไฟล์นี้ตาม

## หลักการ

- Coin ไม่ใช่เงินจริง แลกเป็นเงินไม่ได้ และ **โอนหากันตรง ๆ ไม่ได้**
- ทุกการเคลื่อนไหวของ Coin บันทึกแบบบัญชีคู่ (double-entry) ในตาราง `LedgerTx` / `LedgerEntry`
  - ผลรวม `delta` ของรายการหนึ่งต้องเป็น 0 เสมอ
  - Coin ที่ระบบแจกออกมาจาก wallet `SYSTEM_MINT` และ Coin ที่ถูกใช้หมดไปเข้า `SYSTEM_BURN`
  - ทุกรายการมี `idempotencyKey` กันการจ่ายซ้ำ
- ค่าคงที่ทั้งหมดอยู่ที่ `packages/shared/src/index.ts` (`COIN_RULES`)

### รายละเอียดที่ตัดสินใจไว้ตอนเขียนโค้ด (ขั้นที่ 2)

ข้อเหล่านี้ไม่ได้เขียนไว้ใน Claude Doc ถ้าอยากเปลี่ยน แก้ได้ที่ `apps/api/src/surveys/surveys.service.ts`

- **ค่าโพสต์ไม่คืน** แม้ปิดรับก่อนหรือไม่มีคนตอบ (ถ้าคืนได้ ค่าโพสต์จะไม่มีผลกันสแปม)
- **ผู้โพสต์ต้องลงอย่างน้อยพอจ่าย 1 คน** และลงได้ไม่เกินยอดรางวัลรวม (หักส่วนที่ขอสมทบ) ส่วนที่ขาดรอเพื่อนเติม
- **แบบสอบถามรับคำตอบได้ตราบที่ Escrow ยังพอจ่าย** ถ้า Coin หมดก่อนครบโควตา คนต่อไปจะรับไม่ได้จนกว่าจะมีคนเติม
- **ปิดรับอัตโนมัติ** เมื่อครบโควตาหรือถึงเวลาปิด (เช็กทุก 1 นาที) หรือผู้โพสต์กดปิดเอง
- **ขอระบบสมทบ** → สถานะ "รอแอดมินตรวจ" ยังไม่รับคำตอบ แต่เพื่อนเติม Coin ได้
  - อนุมัติ → สร้าง Coin เข้า Escrow แล้วเปิดรับ
  - ไม่อนุมัติ → เปิดรับตามปกติโดยไม่มีส่วนสมทบ ยอดที่จองไว้ให้เพื่อนเติมแทนได้
  - ปิดก่อนแอดมินตรวจ → ถือว่าไม่ได้ใช้สิทธิ์ ขอใหม่ได้
- **ผู้ที่ตอบแล้วสนับสนุนไม่ได้** และผู้สนับสนุน (รวมผู้โพสต์) ตอบไม่ได้
- **ต้องยืนยันอีเมล @cmu.ac.th** ก่อนรับ Coin จากการตอบ ส่วนการสนับสนุนไม่ต้องยืนยัน
- **จำนวนข้อนับจากคำถามจริง** ที่สร้างในแบบสอบถาม (ใช้คิดรางวัลขั้นต่ำและค่าโพสต์)
- บันทึกคำตอบและจ่าย Coin อยู่ในธุรกรรมเดียวกัน — ถ้าจ่ายไม่ได้ คำตอบก็ไม่ถูกบันทึก
- เศษจากการคืนตามสัดส่วนให้คนที่มีเศษทศนิยมมากที่สุดก่อน (largest remainder) ผลรวมตรงพอดีเสมอ

### แบบสอบถามลิงก์ภายนอก (ขั้นที่ 4.5)

ใช้เศรษฐกิจ Coin เดียวกับแบบสอบถามปกติทุกข้อ (รางวัลขั้นต่ำ ค่าโพสต์ ระบบสมทบ เพื่อนสนับสนุน) ต่างกันแค่วิธียืนยันว่าตอบแล้ว

- ผู้โพสต์ใส่ลิงก์ (https) และ **จำนวนข้อในฟอร์มเอง** (ใช้คิดรางวัลขั้นต่ำ/ค่าโพสต์ ระบบตรวจไม่ได้ว่าตรงจริง)
- ระบบสร้าง **รหัสยืนยัน 6 ตัว** ให้ผู้โพสต์ใส่ใน "ข้อความยืนยัน" ของฟอร์ม (หน้าที่ขึ้นหลังกดส่ง)
- ผู้ตอบต้องกด "เปิดแบบสอบถาม" ใน TEMBO ก่อน (บันทึกเวลาเริ่ม) และ **ต้องผ่านไปอย่างน้อย 30 วินาที** จึงกรอกรหัสได้
- **กรอกรหัสผิดได้ 5 ครั้ง** ครบแล้วรับ Coin จากแบบสอบถามนั้นไม่ได้
- ผู้ตอบแต่ละคนมี **รหัสอ้างอิง** คงที่ (แสดงตอนเริ่ม) ผู้โพสต์เพิ่มช่องในฟอร์มให้กรอก แล้วเทียบกับไฟล์ CSV ได้ว่าใครตอบจริง
- ข้อจำกัด: รหัสยืนยันเป็นรหัสเดียวกันทุกคน ถ้ามีคนส่งต่อรหัส อีกคนอาจรับ Coin โดยไม่ได้ตอบ — รหัสอ้างอิงใน CSV ช่วยให้ผู้โพสต์ตรวจย้อนหลังได้

### Event (ขั้นที่ 4)

กฎที่ตกลงกันเมื่อ 13 พ.ย. 2569: ผู้จัดตั้งรางวัลเช็กอินเองผ่าน Escrow และเสียค่าโพสต์ 10 Coin แก้ค่าได้ที่ `EVENT_RULES` ใน `packages/shared/src/index.ts` และตรรกะอยู่ที่ `apps/api/src/events/events.service.ts`

- **ทุก Event ต้องให้แอดมินอนุมัติก่อนขึ้นฟีด** ระหว่างรอ ค่าโพสต์และรางวัลพักใน Escrow
- **ค่าโพสต์ 10 Coin ทุกครั้ง** (ไม่มีสิทธิ์โพสต์แรกฟรีแบบแบบสอบถาม) คืนให้ถ้าไม่ผ่านการตรวจหรือยกเลิกก่อนตรวจ
- **รางวัลเช็กอินไม่บังคับ** ถ้าให้ ต้องระบุจำนวนคนที่ได้รางวัล (ไม่เกินจำนวนที่รับ) และ Coin ทั้งหมดถูกล็อกตั้งแต่ตอนสร้าง
- **ลงทะเบียนในแอปเสมอ** ถ้าผู้จัดใส่ลิงก์ฟอร์ม (เช่น Google Form) ผู้ใช้กรอกฟอร์มนั้นต่อเอง ระบบไม่ได้ตรวจว่ากรอกแล้ว
- **เต็มแล้วเข้าคิวรอได้** มีคนยกเลิก → คนแรกในคิวเลื่อนขึ้นอัตโนมัติ / ลงทะเบียนใหม่หลังยกเลิกต้องต่อท้ายคิว
- **ผู้จัดลงทะเบียน Event ของตัวเองไม่ได้** / เช็กอินแล้วยกเลิกการลงทะเบียนไม่ได้
- **เช็กอิน**: ผู้จัดเปิด QR ที่หน้างาน รหัส 6 ตัวเปลี่ยนทุก 60 วินาที (รับรหัสก่อนหน้า 1 รอบ) เปิดเช็กอินตั้งแต่ 60 นาทีก่อนเริ่มถึง 120 นาทีหลังจบ ต้องลงทะเบียน (ไม่ใช่คิวรอ)
- เช็กอินได้แม้ยังไม่ยืนยัน @cmu.ac.th หรือรางวัลหมด แต่จะไม่ได้ Coin
- **ไม่สนใจ** = ซ่อน Event นั้นจากฟีดของผู้ใช้คนนั้น

### ฟีดของคุณ (ขั้นที่ 5) — รางวัลสูงช่วยดันฟีด แต่ไม่ชนะความสนใจ

คะแนนอยู่ที่ `scoreFeedItem` ใน `packages/shared/src/index.ts`

| ปัจจัย | คะแนน |
|---|---|
| หัวข้อตรงกับความสนใจของผู้ใช้ | +2 ต่อหัวข้อ (สูงสุด 3) |
| แบบสอบถามจากคณะเดียวกัน | +1 |
| รางวัลแบบสอบถาม | 0–1.5 (รางวัล ÷ ค่าแนะนำตามจำนวนข้อ) |
| Event ที่ยังมีรางวัลเช็กอิน | +0.5 |
| ใกล้ปิดรับใน 48 ชม. / Event เริ่มใน 3 วัน | +0.5 |

รางวัลดันได้สูงสุด 1.5 ซึ่งน้อยกว่าการตรงความสนใจ 1 หัวข้อ (2) คนที่มี Coin เยอะจึงกินพื้นที่ฟีดทั้งหมดไม่ได้ ฟีดของคุณแสดงเฉพาะโพสต์ที่ตรงความสนใจหรือคณะ (ถ้าไม่มีเลยจะแสดงทั้งหมด) และไม่แสดงของตัวเองหรือที่ทำไปแล้ว
