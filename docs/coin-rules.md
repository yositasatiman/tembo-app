# กฎระบบ Coin ของ TEMBO

> ฉบับเต็มอยู่ใน Claude Doc: https://claude.ai/artifact/G1VWCbTfdCHmRB6AKAkRgA
> ไฟล์นี้สรุปไว้ให้คนเขียนโค้ดอ้างอิง ถ้าสองที่ไม่ตรงกัน ให้ถือ Claude Doc เป็นหลัก แล้วแก้ไฟล์นี้ตาม

## หลักการ

- Coin ไม่ใช่เงินจริง แลกเป็นเงินไม่ได้ และ **โอนหากันตรง ๆ ไม่ได้**
- ทุกการเคลื่อนไหวของ Coin บันทึกแบบบัญชีคู่ (double-entry) ในตาราง `LedgerTx` / `LedgerEntry`
  - ผลรวม `delta` ของรายการหนึ่งต้องเป็น 0 เสมอ
  - Coin ที่ระบบแจกออกมาจาก wallet `SYSTEM_MINT` และ Coin ที่ถูกใช้หมดไปเข้า `SYSTEM_BURN`
  - ทุกรายการมี `idempotencyKey` กันการจ่ายซ้ำ
- ค่าคงที่ทั้งหมดอยู่ที่ `packages/shared/src/index.ts` (`COIN_RULES`)

| เหตุการณ์ | Coin | ขั้น |
|---|---|---|

### รายละเอียดที่ตัดสินใจไว้ตอนเขียนโค้ด (ขั้นที่ 2)

ข้อเหล่านี้ไม่ได้เขียนไว้ใน Claude Doc ถ้าอยากเปลี่ยน แก้ได้ที่ `apps/api/src/surveys/surveys.service.ts`

- **ค่าโพสต์ไม่คืน** แม้ปิดรับก่อนหรือไม่มีคนตอบ (ถ้าคืนได้ ค่าโพสต์จะไม่มีผลกันสแปม)
- **ผู้โพสต์ต้องลงอย่างน้อยพอจ่าย 1 คน** และลงได้ไม่เกินยอดรางวัลรวม (หักส่วนที่ขอสมทบ) ส่วนที่ขาดรอเพื่อนเติม
- **แบบสอบถามรับคำตอบได้ตราบที่ Escrow ยังพอจ่าย** ถ้า Coin หมดก่อนครบโควตา คนต่อไปจะรับไม่ได้จนกว่าจะมีคนเติม
- **ปิดรับอัตโนมัติ** เมื่อครบโควตาหรือถึงเวลาปิด (เช็กทุก 1 นาที) หรือผู้โพสต์กดปิดเอง
- **ขอระบบสมทบ** → สถานะ "รอแอดมินตรวจ" ยังไม่รับคำตอบ แต่เพื่อนเติม Coin ได้
  - อนุมัติ → สร้าง Coin เข้า Escrow แล้วเปิดรับ
  - ไม่อนุมัติ → เปิดรับตามปกติโดยไม่มีส่วนสมทบ ยอดที่จองไว้ให้เพื่อนเติมแทนได้
  - ปิดก่อนแอดมินตรวจ → ถือว่าไม่ได้ใช้สิทธิ์ ขอใหม่ได้
- **ผู้ที่ตอบแล้วสนับสนุนไม่ได้** และผู้สนับสนุน (รวมผู้โพสต์) ตอบไม่ได้
- **ต้องยืนยันอีเมล @cmu.ac.th** ก่อนรับ Coin จากการตอบ ส่วนการสนับสนุนไม่ต้องยืนยัน
- **จำนวนข้อนับจากคำถามจริง** ที่สร้างในแบบสอบถาม (ใช้คิดรางวัลขั้นต่ำและค่าโพสต์)
- บันทึกคำตอบและจ่าย Coin อยู่ในธุรกรรมเดียวกัน — ถ้าจ่ายไม่ได้ คำตอบก็ไม่ถูกบันทึก
- เศษจากการคืนตามสัดส่วนให้คนที่มีเศษทศนิยมมากที่สุดก่อน (largest remainder) ผลรวมตรงพอดีเสมอ
